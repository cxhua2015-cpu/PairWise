# expirytable359

并发安全的内存型“到期状态表”，仅依赖 Go 标准库（Go 1.22+）。表使用显式非负单调时间，支持批量 Put/Touch/Delete、边界为闭区间的到期淘汰（`ExpiresAt <= Now`）以及一致性快照。

## 索引

- 主索引为 `map[string]Entry`，键到条目 O(1) 定位。
- 不维护堆等额外结构；到期淘汰采用全表扫描，换取实现的简单与无锁竞争窗口（单互斥串行化）。
- `Snapshot` 与 `Expire` 返回的条目按字典序排序，保证规范、可比较的输出顺序。

## 候选事务

`Apply` 分两阶段执行：

1. **校验**：先对整个批次做完整结构校验（kind 合法、键为非空 ASCII 小写字母/数字/连字符/下划线且不超 `MaxKeyBytes`），再检查时间（非负且不后退）。校验失败不触碰任何状态。
2. **候选执行**：在条目表的克隆副本上先删除 `ExpiresAt <= Now` 的条目，再顺序执行 Put/Touch/Delete（Put/Touch 分配递增 revision）。最终容量超限或任何错误（`ErrNotFound`/`ErrCapacity`）直接丢弃候选，淘汰、时间与 revision 一并回滚；成功才整体提交，`generation` 恰好加一（空批次不变）。

## 所有权

- 所有公开方法通过单个互斥锁串行化，可安全并发调用。
- `Expire` 与 `Snapshot` 返回的切片均为新分配的副本，调用方可自由修改，不影响内部状态；反之内部后续变更也不会反映到已返回的切片。
- 键与条目按值拷贝，表不保留调用方传入批次的任何引用。

## 复杂度

- `Apply`：O(n + m)，n 为当前条目数（克隆与淘汰扫描），m 为批次内操作数。
- `Expire`：O(n + k log k)，k 为到期条目数（排序）。
- `Snapshot`：O(n log n)（拷贝并排序）。
- 空间：O(n)。
